# Follow Me — 전 스테이지 레벨 디자인 (S1~S16)

> KDS 전용. **아트** = `Docs/Story_FollowMe.md` / **리듬** = 스마일모 (`LevelDesign_Guide.md`)  
> S1 상세는 `Stage1_LevelDesign.md`와 동일. 본 문서는 S1~S16 통합 스펙.

## 공통

- **6모듈**: Intro → Teach → Pressure → Breath → Setpiece → Goal
- **월드 스케일**: 1u ≈ 1m, 지면 Y ≈ 0, 카메라 orthographic size ≈ 5~6
- **갈림**: 상=좋아요 / 하=일상(답장·밥·잠). 둘 다 통과 가능, 정산 수치만 변경
- **괴물**: 씬 미리 배치 → 모드 토글. 안정→추격 직행 금지, **경고 구간** 필수
- **포토**: E 홀드(Interact) 1회성. SO `08.SO/PhotoPoint/`
- **맵 템플릿**: T1 번화가 / T2 카페거리 / T3 불꽃축제 / T4 지하철
